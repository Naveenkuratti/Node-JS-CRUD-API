# 🚀 Node-JS-CRUD-API

A simple RESTful CRUD API built using **Node.js**, **Express.js**, **MongoDB Atlas**, and **Mongoose** for managing contact data.

## 🔧 Tech Stack
Node.js | Express.js | MongoDB Atlas | Mongoose | Dotenv | Nodemon

## 📌 Features
- Create Contact
- Get All Contacts
- Get Contact by ID
- Update Contact
- Delete Contact

## ⚙️ Setup

```bash
git clone https://github.com/Naveenkuratti/Node-JS-CRUD-API.git
cd Node-JS-CRUD-API
npm install

MONGO_URI=your_mongodb_connection_string
PORT=5000

npm run dev
Server runs at:
http://localhost:5000

🔗 API Endpoints

GET /api/contacts
GET /api/contacts/:id
POST /api/contacts
PUT /api/contacts/:id
DELETE /api/contacts/:id
