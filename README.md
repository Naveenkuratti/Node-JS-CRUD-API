# 🚀 Node-JS-CRUD-API

A RESTful CRUD API built using **Node.js**, **Express.js**, **MongoDB Atlas**, and **Mongoose** for managing contact data.

---

## 📌 Features

- ✅ Create Contact
- ✅ Get All Contacts
- ✅ Get Contact by ID
- ✅ Update Contact
- ✅ Delete Contact
- ✅ MongoDB Atlas Integration
- ✅ Proper Error Handling
- ✅ Tested using Postman

---

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Nodemon
- Dotenv
